# Identity & market

## Identity

**Storylint is a writing IDE for serial / world-heavy fiction, with a project-aware agent panel.**

Primary analogy: **VS Code + Claude extension (or Cursor)** — not “notes + ChatGPT,” not “Sudowrite with a binder,” not “anti-AI calm app.”

| IDE world | Storylint |
|-----------|-----------|
| Workspace | Book project |
| Source files | Chapters + bible sheets |
| Editor | Manuscript (clean) |
| Agent sidebar | **Agent panel** (first-class) |
| @codebase / @file | @bible / @chapter / @sheet / selection |
| Diff apply | Apply to manuscript |
| Accept into config/docs | Accept into sheets (canon) |
| Diagnostics | Continuity yellow/red marks |
| Multi-step agent | Review, extract, research, co-write |

### One-liner

Fiction IDE: draft on a clean page; agent knows your world and works with you; **you accept** what enters the book or canon.

### Positioning

> Like VS Code + Claude, for your novel.

### What we are not

| Anti-identity | Why |
|---------------|-----|
| Sudowrite-class gen cockpit | Gen tools live in the **agent panel**, not as chips inside the prose surface |
| Calliope-only “AI must never co-write” | Co-write is allowed via **Apply**; ideology is ownership, not abstinence |
| Obsidian DIY | Novel-native binder + agent tools out of the box |
| Full autopilot novelist | Unattended whole-book generation is out |
| Format factory | EPUB/print is exit ramp later, not the product |

### Brand of help

- Agent is a **real pair** (capable, project-aware), not a shy footnote  
- Human remains **main writer** and **main canon owner**  
- Clean editor = less need to maintain a parallel note pile when agent reviews/proposes well

## Market

### Beachhead

| In | Out (for now) |
|----|----------------|
| Serial / web-novel authors | Pure format/publish tooling users as core |
| Multi-POV, long continuity, secondary worlds | One-off shorts with no bible pain |
| People who already like Cursor / Claude Code / Copilot sidebar | Users who refuse any AI |
| Local-first single author (**you first**) | Teams, SSO, multi-tenant SaaS |
| Want fewer manual notes via agent review | “Write my novel while I sleep” |

### Jobs-to-be-done

1. Draft without chrome fighting the words  
2. Keep canon honest across dozens of chapters  
3. Let the agent grow/check the bible so notes don’t explode  
4. **Create and deepen sheets with agent help** (Accept-gated), lore-aware suggestions OK  
5. Newbie guidance without heavy courseware  
6. Co-write on demand in the agent panel  
7. Later: E2E sense-check (plot, culture, missing world logic)  
8. Later: **Research panel** — clean, cited, powerful  
9. Later: **Graph/canvas** of relationships (father, org, rival…)  
10. Sheet identity: optional **portrait/icon** on characters  

### Competitive frame (short)

| Player | Owns | Gap we take |
|--------|------|-------------|
| Docs / Word | Default words | No novel agent + bible lint |
| Scrivener | Fiction-native gravity | Modern agent pair; calm apply UX |
| Obsidian / Anytype | Flexible local knowledge | Novel agent + continuity diagnostics |
| Novelcrafter | Codex + AI suite | Cleaner editor/agent split; accept discipline |
| Sudowrite | Generation | Project canon + IDE apply model |
| Calliope | Continuity companion | Full agent panel + optional co-write apply |
| ChatGPT tab | Generic help | Bound to *this* project’s bible/chapters |

### Messaging do / don’t

| Do | Don’t |
|----|--------|
| “IDE + agent for your serial” | “AI stays in the margins” (undersells) |
| “Accept before it hits canon or the page” | “We never help you write” |
| “Fewer notes because the agent reviews” | “Set and forget novel factory” |
