## How to add a decision

1. `docs/decisions/<traceable-name>.md` with banner (author, kind, decided one-liner).  
2. One line in the **Index** table: what it **DECIDED**.  
3. If it overturns something, add a **Supersession** row — do not delete the old file.  
4. If it is a standing rule, add one bullet to [STANDING_RULES.md](./STANDING_RULES.md).  
5. Cite shot paths; do not commit shot folders.
