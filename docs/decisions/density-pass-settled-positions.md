# Density pass — settled product positions

**Voice:** ox  
**When:** close of the density / under-load pass (dev green @ `d06e114` era; binder scroll-restore still the last product hold before milestone two)  
**What this is:** the **conclusions**. Not the incident log. Not the calm scoreboard.  
**What this is not:** permission to skip evidence. New measurement can reopen a row. Opinion cannot.

If you are about to propose People/Places, a center-stage sheet, a hard three-face Companion, global Apply-locks-with-Continuity, or Lab-as-forever-audit — **stop**. Those were heard, tried, or ruled. The citations are the long form; this page is the short form.

## 2. Primaries, solids, and doors

### 2.1 One solid primary per job (whole viewport)

| Position | Therefore | Cite |
|---|---|---|
| **One solid primary per job**, counted **across regions**, not per panel. | Two solid “New sheet” or two first-chapter doors in one viewport is a fail even if each region looks fine alone. | [one-primary-door-per-job](./one-primary-door-per-job.md) · calm **B6-primary-per-job** |
| Same verb + same destination = **one job**. | Second door demotes (ghost) or hides. | same |

### 2.2 Runnable-solid (entitlement sibling)

| Position | Therefore | Cite |
|---|---|---|
| A **solid must not advertise a job that cannot succeed** in the current state. | Empty-body Continuity must not look runnable. Empty Canon must not wear a solid Send that cannot complete a real proposal path. Check entitlement, not only paint. | [runnable-solid-precondition](./runnable-solid-precondition.md) |
| Weight and entitlement are **different axes**. | Demote weight without lying about readiness; gate readiness without only greying mystery. | same · [empty-canon-send-proposal-weight](./empty-canon-send-proposal-weight.md) |
| **B6 letter ≠ runnable spirit.** B6 counts **competition** (how many solids fight for attention). Runnable-solid gates **entitlement** (can this job succeed now). | **Passing either alone is insufficient.** Empty Canon can pass B6 (New sheet + Send are different jobs) and still fail runnable-solid if Send is solid with no path. We have been bitten. | same · empty-canon-send |
| After demote, a **ghost** peer must still read as a control (silhouette / contrast). | Demote must not create hidden affordances. | [ghost-control-silhouette-ruling](./ghost-control-silhouette-ruling.md) |

### 2.3 Empty, seeded, full are different states

| Position | Therefore | Cite |

| **Seeded-default** is a **third** arrival — not empty, not populated prose. | Fixtures must cover **true-empty / seeded-blank / populated**. One “empty” fixture is not enough. | [seeded-default-first-impression](./seeded-default-first-impression.md) · [boolean-hides-multi-state](./boolean-hides-multi-state.md) |
| **Seed branch predicates (do not “fix” these):** create-door weight keys off **row existence** (`chapters.length`), not title fullness. ## 3. Companion

### 3.1 One assistant, one job — and decisions are not jobs

| Position | Therefore | Cite |
|---|---|---|
| Companion is **one assistant doing one in-flight job**. | No run-id parallel lanes. One busy lexicon for jobs. Face shows **this run’s** outcome, not stale success from a prior run. | [companion-one-assistant](./companion-one-assistant.md) |
| **Jobs** share `assistantBusy` (Chat, cowrite/Spark, Continuity Check, Research **query**). | Starting a second job while one runs is blocked both ways. | [companion-lock-jobs-vs-decisions](./companion-lock-jobs-vs-decisions.md) |
| **Decisions** stay free under jobs: Inbox Accept/Edit/Reject, **Apply/Dismiss**, Research **Pin/Propose**. Local busy only. | Do **not** put Apply on `assistantBusy`. Mutex-A “everything mutates shares one lock” is **rejected**. | same |
| **Draft stays typeable** while a companion job runs. | Companion busy ≠ app freeze. The manuscript is not a hostage. | same · AV perimeter |
| **A panel is not a unit of work.** Research is **two kinds** of work in one panel (query = job; pin/propose = decisions). | Do not gate a whole face because one control inside it is a job. | same |
| **Author’s last explicit write wins** for chapter body and proposal Accept. A finishing job may leave **stale** marks/proposals; that is acceptable. Accept is not invalidated mid-flight; the author is not punished for deciding during a run. | Do not invent distributed locks or freeze Inbox “until Continuity settles.” Generation/mutation stamps are transport, not a second product model. | same |

### 3.2 Writing chrome shape

| Position | Therefore | Cite |
|---|---|---|
| Daily loop: **Chat · Write · Check**; **Inbox** always present (badge when pending); **Research** quiet / More. | Not five equal primaries. Not a hard “≤3 faces total” ship gate that deletes Inbox or Research (hides the pending count or the episodic tool). Allow-list may be 5; **≤3 primary peers**. | [design-review-d6](./design-review-d6.md) · [research-face-shape](./research-face-shape.md) · calm-budget-authority |
| Continuity lives **only** as Check. | No Continuity return to the top bar. | IA · milestone |
| **Build the control cardinality justifies.** One overflow target → plain control, not a one-item menu costume. | Full APG menu greenlight at cardinality one is **retracted**. | [research-face-shape](./research-face-shape.md) |

### 3.3 Inbox under load

| Position | Therefore | Cite |
|---|---|---|
| Inbox at volume is a **fold + quiet count**, not a wall and not bulk Accept. | First fold ~4; overflow in closed disclosure; `N pending`. No “Accept all.” | [draft-under-load-av](./draft-under-load-av.md) · AY land · [b3-inbox-wall-at-volume](./b3-inbox-wall-at-volume.md) |
| Continuity multi-run does not reopen as a wall. | ~20s continuity path stays reviewable without dumping the rail. | draft-under-load-av |
| Stack/scroll/Inbox promises are **unverified until measured at volume**. | Fixture size is part of the claim. | AZ · BA · AY |

## 11. One paragraph for the next designer

Storylint’s desk is **three ecosystems** and **one companion**. Primaries are counted **across the whole viewport**, and a solid button is a promise the current state can keep — **B6 without runnable-solid is not enough**. The companion runs **one job at a time** but does not hold the author’s **decisions** or **Draft typing** hostage; the author’s last explicit write wins. Canon changes only through an **explicit** Accept or Save; Lab may be messy and may **forget receipts** without rewriting history. Boot seeds a **blank-titled** chapter row; New project has **no** chapters; seeded is a third state — branch on row existence for create doors and on body prose for Continuity, never on “feels empty.” We already tried the friendly kind rename, the center sheet, and the three-face diet; the product is calmer because we **refused** them, not because we never saw them.
