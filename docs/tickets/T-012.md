## Context

Canon renders two identically-weighted primary buttons for the same verb in a single view: the
binder CANON section button and the centered empty-state CTA. Duplicated primary weight means
neither reads as *the* next action.

The rest of the product is disciplined about this, which is why it stands out.

## Acceptance detail

- [ ] Exactly one primary "New sheet" in any single Canon view state
- [ ] The demoted one is quiet/secondary, still reachable
- [ ] The choice is stated with its reason (wayfinding vs durable location), so the next
      person does not re-litigate it
- [ ] Non-empty Canon checked too — the duplication may only bite at empty state

## Repro

1. Canon mode, zero sheets, desk width
2. Observe binder CANON section button and centered empty-state CTA
3. Both are primary-styled at the same time
