## Context

The "Propose new edge" input sits below the empty graph before any sheet exists. An edge needs
two endpoints; with zero sheets there is nothing to connect, so the control cannot do its job.

Storylint gates well elsewhere: Continuity will not run without prose. This finding is that Canon
does not apply the same rule to itself.

## Acceptance detail

- [ ] "Propose new edge" is hidden or disabled below 2 canon sheets
- [ ] If disabled rather than hidden, it says why in one line — a dead control with no
      explanation is worse than an absent one
- [ ] Domain check first: confirm a self-edge (one sheet to itself) is not meaningful before
      fixing the threshold at 2
- [ ] The gate follows the same shape as the Continuity-gates-on-prose precedent, so the
      product has one rule rather than two similar ones

## Repro

1. Canon mode, zero sheets
2. "Propose new edge" input is present and interactive
3. Nothing exists that could be an endpoint
