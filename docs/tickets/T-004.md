## Context

Refresh/tab-close drops dirty identity. Navigation leave-guard does not cover process lifetime.

## Binding model

Read **[sheet-identity-durable-dirty.md](../decisions/sheet-identity-durable-dirty.md)** before coding. Short form:

1. Local durable copy of form dirty — **not** autosave, **not** a second Canon write path.
2. Restore **as dirty** (Save still required).
3. If server identity moved since draft `base` → **conflict chooser** (Keep mine / Keep Canon). Do not auto-drop the draft.
4. Keyed `projectId:sheetId`; survives browser restart; no silent TTL; >7 days needs confirm before apply.
5. Clear draft on successful Save and on Discard.
6. Leave dialog unchanged (Save / Discard / Cancel); Discard clears durable draft too.

## Acceptance detail

- [ ] Dirty identity → reload → fields restored **and** dirty; Save still required to write Canon
- [ ] Successful Save → reload → no draft residual
- [ ] Discard → reload → server value; no draft
- [ ] Server identity changed under draft → conflict chooser; neither side auto-wins
- [ ] Draft older than 7 days → confirm before apply
- [ ] No Canon write except existing Save path (standing rule 20)
- [ ] No reliance on beforeunload as sole guard
- [ ] L1 proof on owned stack
