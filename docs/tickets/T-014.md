## Context

Lab correctly uses a full-bleed dark canvas rather than the manuscript paper — workbench, not
manuscript. Inside that canvas, though, the Title input and Notes card stretch to roughly 1900px
at desk width. A single-line title spanning the whole viewport looks unanchored and is a long
mouse travel for a short field.

## Acceptance detail

- [ ] Composer capped to a form column, left-aligned as it is now
- [ ] Width taken from an existing token / documented measure, not a new magic number
- [ ] The full-bleed canvas itself is unchanged — only the composer inside it is capped
- [ ] Checked at the 1366 desk floor as well as wide desk, so the cap does not create
      an awkward narrow case

## Repro

1. Lab mode, desk width
2. Measure the Title input and Notes card width
3. ~1900px against a viewport of 2560
