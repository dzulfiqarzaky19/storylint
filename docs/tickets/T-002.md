## Context

Founder flow pools work on dev until a story completes, then runs composition E2E. L1 (`test:green` / all-smoke) is isolation-shaped. A rule with no runner is a rule nobody follows.

## Gap (what L2 checks that all-smoke does not)

- **all-smoke:** each feature smoke mints a private project; suite asserts post-smoke active ∈ that mint. Sibling contamination is caught; multi-surface shared state is not exercised.
- **L2:** one project P; Draft body written on P; Canon sheet seeded into P; Lab switch; reload; prove body + sheet + active still P.
