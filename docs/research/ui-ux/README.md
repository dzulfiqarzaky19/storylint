## One-line synthesis

**Power tools win when the default path is calm, depth stays shallow, labels match the job, and irreversible truth is always gated.**

That is the same spine as Storylint’s locked map: three ecosystems, max depth 3, companion not a kingdom, Apply/Accept sacred.
